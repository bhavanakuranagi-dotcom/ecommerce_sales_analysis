
# 🛒 E-Commerce Sales Analysis Dashboard

## 📌 Project Overview

This project presents an end-to-end **E-Commerce Sales Analysis** using **Excel, MySQL, Python, and Power BI**. The goal is to analyze sales performance, identify profitable products and categories, monitor regional performance, and provide actionable business insights through interactive dashboards and data visualization.

This project demonstrates the complete data analytics workflow including data cleaning, SQL querying, exploratory data analysis (EDA), dashboard development, and business reporting.

---

## 🎯 Objectives

- Analyze overall sales and profit performance.
- Identify top-selling and most profitable products.
- Compare sales across categories and regions.
- Analyze monthly sales and profit trends.
- Calculate key performance indicators (KPIs).
- Build an interactive Power BI dashboard.
- Generate business insights for decision-making.
